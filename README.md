# bev-diag.github.io (legacy)

The BEV Diag landing page moved to https://bevdiag.com; its source and hosting are in the
`bevcloud-web` repo (`landing/`, stack `BevDiagLanding`).

GitHub Pages still serves this repo from `main` so that old links keep working: every page here,
and `404.html` for any other path, sends the browser to the same path on `bevdiag.com`. Once
nothing links to bev-diag.github.io any more (Google Play, search results), the repo can be removed.
